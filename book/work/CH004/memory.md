# 第 4 章 章后记忆

## 已发生的事实（第 4 章）

- 【4】时间：11-30（周五）下午冷库提肉，12-01（周六）考核日，地点市工人文化宫食堂。
- 【4】提肉：陈永强一张调剂条子，后腿一扇连皮带骨八十三斤四两，牌价八分/斤＋过手费二分/斤，共八块三毛四，当场钱货两讫。她当场修肉：淤血剔净，坐臀最整一块三斤六两单独裁出；筋头碎肉装半个面口袋带走（后成考场救命料）。
- 【4】约定：考完试陈永强送十斤积压咸肉试做（"后天一准到"，即 12-03）。
- 【4】备料夜：硝托马长栓从药房买（两分钱的，名义治口疮）；盐炒过、花椒擀碎；爹的本子口诀"硝盐码味，宁少勿多，筷子头蘸着试，舌尖发麻就过了"。肉码进瓦罐压菜石蒙布，一夜吃味。周念问"那你呢"，她答"考过了，妈就敢说了"。
- 【4】考核：三十四名考生分三组。她号码二十七。纪律：换料换家伙以舞弊论。自备料交考核办库房贴签落锁，保管员（五十来岁瘦子）在签条右下角画了个没写完的勾（她记下了）。
- 【4】指定活：白案题烫面饺皮三十张过秤验匀——她一两不差、张张透光，监考干事记了一笔。马长栓同题过秤（陪考心态）。刘福生红案蓑衣黄瓜出彩。
- 【4】换肉事件：下午领料，她先觉分量不对（沉了）；开罐见注水肉（色白发浮、按坑不回弹、生水腥气）；签条勾的笔画反了、浆糊发黏——旧签泡水重贴，有备而来。
- 【4】验肉：首席评委关学曾（市饮食公司老总厨，解放前掌勺，与赵德山同灶三年，六八年送过他）当众验明：断面渗水珠、刀背压出水声。断语"注水肉，一斤灌进去三两"。保管员被叫来，一问勾的记号即汗下；关学曾让考核办把人看着，"别吓着他"，事后查。
- 【4】自选活：关学曾给半个钟头重新备料。她用面口袋里的碎肉筋头熬皮冻为主，注水肉借碱逼水、重码硝盐后"只配做个陪衬"。水晶肴肉出锅：肉红、冻子茶色、提片见光、颤而不碎。关学曾吃出"赵德山的味道"，眼圈发红："你爹切肉，也是这么个站姿。"
- 【4】口试：发面"差在天不差在手"、烫面看做什么定几分烫；关学曾追问断注水肉凭的是什么，她答色、按、听、分量四样，"厨子骗不了锅，锅骗不了嘴"。
- 【4】结果：特三级通过名单三人——刘福生（红案头一名）、另一人未点名、赵秀兰（白案，红旗饭店）。马长栓未提通过（陪考）。
- 【4】孙爱华冒雪赶来，握手只说一个"好"字——赵秀兰心知这一握才"盖在她身上"（相对第 2 章"盖的是章程"）。
- 【4】王科长当众说换肉案要报公司备案、饭店领导要"配合调查"；钱广成满口应承，眼皮跳了一下。
- 【4】钱广成当众逼献方（"献给集体""觉悟"），她挡回："献方的章程得回去先学学，学明白了当着孙书记的面给准话。"孙爱华在场，眉头动了一下没说话。
- 【4】结尾：入冬头一场雪。她对马长栓说"咱们店里，谁管过库房，您比我清楚"；对爹在天之灵说"你的味道，今天在所有人嘴里，都还叫赵德山"。

## 人物认知与误信

- 【4】关学曾已知：她是赵德山之女、手艺是真传；不知她重生。他这条线是她在公司系统里第一个高位善意。
- 【4】钱广成误判：以为换肉能让她自选活开天窗，没算到她拿碎肉翻盘；当众逼献方被她用"章程"拖住——他眼下还没意识到换肉案会查到他库房那条线。
- 【4】赵秀兰知而未点破：换肉方向指向钱广成（库房保管线）；她手里物证是那张反笔画的签条。
- 【4】孙爱华对献方的真实态度未明（眉头一动没说话），第 5 章亮牌。
