# 第 3 章 章后记忆

## 已发生的事实（第 3 章）

- 【3】时间：1979-11-29（周四）。收条一早送回：市饮食公司考核办红戳，11-28 十六时五十分收讫，补报成立。考核后天（12-01）开考。
- 【3】章程细则：自选活主料考生自备，凭本店介绍信与肉票购买；特三级三项全考（指定活、自选活、口试），自选活弃权记零分。
- 【3】肉票家底：每人每月半斤；她攒了一冬共二斤二两，原打算留过年。做一坛水晶肴肉需净肉三斤往上，须后腿坐臀。
- 【3】上一世事实（仅她与读者知）：这个冬天食品公司冷库一批冻车挤压的砸伤后腿肉内部处理，八分钱一斤、不要票、需单位介绍信；钱广成批了二百斤发福利，还凭"节约开支"汇报上了简报。本世这批肉"前天"已被红旗饭店（钱广成）拉走最后二百斤。
- 【3】陈永强登场：供销系统驻北方采购员，三十五六岁，瘦长脸，军大衣里穿的确良，南方口音，话要折半听。手里压着一批去年腌的积压咸肉，再压一个冬就走油。
- 【3】谈判结果：窝棚里立字据（看车人画押见证，一式两份，陈永强签名按手印）：一、陈代赵接洽冷库损耗肉，按库内牌价，过手费每斤二分；二、赵以陈供积压咸肉配鲜肉制肴肉，陈负责运销，货款回收后赵三陈七，每批一结；三、试做十斤，成色不合料钱由赵承担；四、各执一份。
- 【3】定价盘算（她口头报的账）：砸伤后腿八分/斤，修淤血出七成好肉；肴肉半斤一块走供销社门市卖四毛，刨料工过手净剩两毛出头。
- 【3】政策边界已写明：双方约定肉走调剂条子、肴肉走供销社代销、公对公开条子，不碰私货（投机倒把是红线）。
- 【3】陈永强额外交底：库里还压着一扇没挂牌的后腿（上月损耗挑剩），明天下午弄出来给她留着，连皮带骨八十来斤，净肉五十斤上下——考核用肉＋试做头一锅都有了。
- 【3】尾钩：分手路口陈永强问"这肴肉方子，卖吗？"她答"方子不卖。肴肉管够，方子没有。"她事后拆出破绽：采购员该问产量运费，偏问方子——要方子的是想自己做自己卖的人，或替人探路的。她第一次把上一世方子倒手的悬案与具体的人对上号（未坐实）。
- 【3】家线：王金花这几天没来闹（张婶接济念儿吃晚饭时转述）；她判断婆婆在等她把日子过塌。夜里她把人生第一张字据夹进父亲笔记本的方子页；决定明天割那二斤二两肉票给念儿炖肉。

## 人物认知与误信

- 【3】陈永强已知：她是红旗饭店白案师傅、赵德山之女、要考特三级、急着要好后腿；不知她情报真实来源（她给的是行情推断，他选择不问）；误以为她的精明"有人教过"。
- 【3】读者知而她不知：上一世买走方子的就是陈永强（本书时间线内尚未发生，也不必然再发生）；他问方子是否替人所问，她只有怀疑没有证据。
- 【3】钱广成不知：他拉走的二百斤砸伤肉反而帮她确认了冷库这条路；更不知她已搭上供销社渠道。
