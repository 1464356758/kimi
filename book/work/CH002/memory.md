# 第 2 章 章后记忆

## 已发生的事实（第 2 章）

- 【2】时间：1979-11-28（周三），报名截止日。本章从凌晨接第 1 章，至当夜结束。考核三天后开考（12-01 前后），科目：指定活、自选活、口试；自选活特色原料自备。
- 【2】章程第十二条原文级内容：本店三级以上厨师三人联名举荐可补报，截止当日下午五时前送达市饮食公司考核办公室。
- 【2】店内三级以上正式厨师共四人：马长栓（白案）、刘福生（红案）、田守义（小灶）、钱广成（三级红案出身转管理）。
- 【2】她上午求签两度碰壁：刘福生踢皮球（"把老田说动再来"）、田守义讲脸面（"多一事不如少一事"）。
- 【2】中午职工餐她自掏腰包加做两大屉烫面蒸饺（小芹面和死了她救回）；洗碗间老师傅、前堂服务员全吃到；老主顾清晨已认出口味。
- 【2】三个签名顺序：马长栓（饭后主动，掏出别了三十年只领工资才用的钢笔）、田守义（孙书记表态后）、刘福生（众人目光下，"别拉上我"）。
- 【2】孙爱华书记：部队转业，讲程序，盯评级先进。当众定调"按章程办，不算谁得罪谁"；下午四点在办公室当着钱广成签"情况属实，同意补报"并盖公章，通讯员小于四点二十送走材料，五点死线前送达（收条未明写，默认送到）。
- 【2】赵秀兰当众点破"报名表被想到抽屉里"，马长栓作证交表在场（上礼拜三班组学习散会时交）。
- 【2】钱广成败后退到暗处：库房里对保管员低语"考核那天的料……你先……"（她只听见半句）；办公室撂话"考场如战场，刀勺无眼"。
- 【2】孙书记私下对她交底："盖的是章程，不是你"，考砸算书记头上。赵秀兰答"我爹是赵德山"。
- 【2】王金花白天在胡同口骂了半晌午，张婶等街坊替她辩白（彩礼原样退回已成本院公论）；王金花撂话"这事没完"。
- 【2】她已决定自选活做水晶肴肉，理由是"守不是藏"。

## 人物认知与误信

- 【2】钱广成已知：她清楚表被压下，且敢当众点破；他误认为她只有章程这一招，没意识到她听见了库房半句。
- 【2】孙爱华知道表被压的嫌疑存在（"回头再说"），暂未追究——这笔钱广成欠着。
- 【2】马长栓、田守义、刘福生都知道她手艺出自赵德山；全店职工经此一章普遍认出"同和居赵师傅的女儿"。
- 【2】读者知而她不知：库房半句的具体内容；钱广成的下一步手段。
